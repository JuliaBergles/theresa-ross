# Phase 1 — Test-Struktur und Fragen

> Zur Freigabe durch Theresa. Erst nach OK wird gebaut.

---

## Ablauf

Der Test hat 4 Abschnitte + 1 Abschlussfrage. Dauer: ca. 10-15 Minuten.
Jede Frage wird einzeln angezeigt (eine pro Bildschirm), mit sanftem Übergang.
Progress-Bar zeigt den Fortschritt.

Am Ende: Ergebnis direkt im Browser (kein Mail-Versand nötig).
Danach optional: E-Book-Download per E-Mail.

## Scoring-Übersicht

**Fragen mit Punktwert (11 Fragen):**
B1, B2, B3, B4, B5, C1, C2, C3, C5, D1, D2, D3, D4

**Maximale Punktzahl:** 11 × 3 = 33 Punkte

**Cluster-Grenzen:**
- 0-8 Punkte → Cluster A (entspanntes Nervensystem)
- 9-17 Punkte → Cluster B (erste Anzeichen)
- 18-27 Punkte → Cluster C (spürbar belastet)
- 28-33 Punkte → Cluster D (ärztliche Begleitung)

**Cluster-D-Override (unabhängig von Punktzahl):**
Cluster D wird automatisch ausgelöst wenn ALLE drei zutreffen:
- B3 Schlaf = "morgens erschöpft" (3 Punkte)
- B4 Energie = "meistens erschöpft" (3 Punkte)
- B5 Anspannung = "fast immer" (3 Punkte)

**Krisen-Override:**
Freitext-Felder (A3, C4, E1) werden auf Krisen-Wörter geprüft.
Bei Treffer: sofortige Unterbrechung mit Hilfsangebot (siehe Phase 4).
