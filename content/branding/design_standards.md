# Design-Standards für Karussell-Slides

## Format & Grundraster
- **Slide:** 1080 x 1350 px (Instagram Hochformat)
- **Safe Area:** 80 px Abstand von allen Seiten, 100 px oben/unten
- **Effektiver Inhaltsbereich:** 920 x 1150 px

## Text-Ausrichtung
- Standard: zentriert, vertikal optisch mittig
- Bei Bild-Slides: Text oberes oder unteres Drittel, nie quer durchs Bild
- Headline und Body auf gleicher Mittelachse

## Zeilenlänge
- Headline: 18-22 Zeichen pro Zeile
- Body: 30-40 Zeichen pro Zeile
- Manuelle Umbrüche an sinnvollen Stellen
- Keine alleinstehenden Einzelworte am Zeilenende

## Schriftgrößen
| Element | Größe |
|---------|-------|
| Hook (Slide 1) | 72-88 px |
| Headline (mittlere Slides) | 56-68 px |
| Body | 32-40 px |
| Untertitel/Hinweise | 24-28 px |
| Logo/Signatur | 22-26 px |
| **Minimum** | **24 px** |

## Zeilenabstand
- Headline: 1.15
- Body: 1.4
- Nie unter 1.0, nie über 1.6

## Abstände
- Headline zu Body: 40-60 px
- Body zu CTA: 60-80 px
- Bild zu Text: 60 px
- Logo zum unteren Rand: 80 px
- Symbole zu Text: 30-40 px

## Deutsche Typografie
- Anführungszeichen: „Gänsefüßchen" (deutsch)
- Apostroph: typografisch (U+2019)
- Auslassungspunkte: … (U+2026)
- Geschütztes Leerzeichen vor Einheiten

## Kontrast
- WCAG AA: mind. 4.5:1 für Body, 3:1 für große Schrift
- Bei Bild-Hintergründen: halbtransparentes Overlay

## Export
- PNG, RGB, sRGB-Farbprofil
- 1080 x 1350 px
- Benennung: slide_01.png, slide_02.png, ...
